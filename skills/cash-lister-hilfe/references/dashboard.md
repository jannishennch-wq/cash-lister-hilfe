# Das Dashboard und die Seitenleiste

Dieser Bereich erklärt die Startseite von Cash Lister, das **Dashboard**, und die **Seitenleiste**, die links auf jeder Seite von Cash Lister steht. Hier steht, wie du das Dashboard öffnest, was jede Zahl, jede Karte und jeder Knopf bedeutet, wie du dich anmeldest und abmeldest, was die Abo-Anzeigen sagen und was du siehst, wenn der Server nicht erreichbar ist.

> Hinweis für die Hilfe: Alles hier ist am aktuellen Stand der Extension (Version 46.3) geprüft. Beschriftungen stehen genau so in Anführungszeichen, wie sie auf dem Bildschirm erscheinen. Stellen mit **Nicht sicher belegt:** sind offene Punkte. Sag dem Kunden dort ehrlich, dass du es nicht sicher weißt, und verweise ihn an den Betreiber. Erfinde nichts dazu. Zahlen in Beispielen (z. B. „370 von 1.000“, „Server-1“) sind nur Beispiele.

## 1. Was das Dashboard ist

Das **Dashboard** ist die Startseite von Cash Lister. Es ersetzt seit Version 46.0 das kleine Fenster (Popup), das früher beim Klick auf das Cash-Lister-Symbol aufging.

Das Dashboard zeigt dir auf einen Blick:

- ob du angemeldet bist und ob der Server erreichbar ist,
- wie viele Angebote du hast, wie viele Produkte in deiner Produkt-Datenbank liegen und wie viele heute gelistet wurden,
- was Tracker, Browser-Lister und (falls du ihn nutzt) CSV-Lister gerade tun,
- eine kleine Tages-Checkliste („Heute“),
- Hinweise, wenn etwas deine Aufmerksamkeit braucht (Glocke oben rechts),
- dein Abo (Karte „Dein Abo“), sobald für dich eine Abrechnung läuft.

Außerdem meldest du dich **im Dashboard an** und ab. Ein Klick auf eine Karte oder auf einen Eintrag in der Seitenleiste öffnet das passende Modul in einem eigenen Tab.

Wichtig zum Verständnis:

- **Das Dashboard zeigt fast nur an.** Es startet und stoppt keine Läufe. Du kannst es jederzeit schließen; Tracker, Browser-Lister und CSV-Lister laufen in ihren eigenen Tabs weiter. Was du dort startest und stoppst, steht in `tracker.md`, `listen-auf-ebay.md` und `produktuebersicht-und-csv-lister.md`.
- **Was das Dashboard beim Öffnen von selbst tut:** Es fragt einmal nach, ob deine Anmeldung noch gilt (dafür fragt die Extension im Hintergrund beim Server nach). Bei einem frisch eingerichteten Chrome-Profil schaltet es außerdem drei Grundeinstellungen ein, falls sie noch gar nicht gesetzt sind: „Listing automatisch absenden“, „Pflicht-Artikelmerkmale mit KI ausfüllen“ und „Optionale Artikelmerkmale mit KI ausfüllen“ (zu finden unter Einstellungen → Reiter „Preise & Listing“). Hast du diese Schalter schon einmal selbst gestellt, ändert das Dashboard nichts daran.
- **Der Tab heißt** „Cash Lister – Dashboard“.

## 2. Das Dashboard öffnen

**Weg 1: Klick auf das Cash-Lister-Symbol** (oben rechts in Chrome, neben der Adresszeile).

1. Klick einmal auf das Cash-Lister-Symbol.
2. Ist das Dashboard noch nicht offen, öffnet es sich in einem **neuen Tab**.
3. Ist das Dashboard schon irgendwo offen (auch in einem anderen Chrome-Fenster), **springt** der Klick zu diesem Tab und holt sein Fenster nach vorn. Es entsteht kein zweiter Dashboard-Tab.

Das Symbol ist das Logo von Cash Lister: ein dunkelblaues, abgerundetes Quadrat mit drei nach rechts höher werdenden Stapeln (blau, türkis, gelb) und einem kleinen Funkelstern.

**Weg 2: über die Seitenleiste.** Auf jeder Seite von Cash Lister (Einstellungen, Tracker, Browser-Lister usw.) steht links die Seitenleiste. Der oberste Eintrag „Dashboard“ bringt dich zurück zum Dashboard (siehe [Abschnitt 4](#4-die-seitenleiste)).

**Symbol nicht zu sehen?** Allgemeines Chrome-Wissen, nicht aus Cash Lister: Chrome versteckt Erweiterungen oft hinter dem Puzzle-Symbol rechts neben der Adresszeile. Klick auf das Puzzle-Symbol und dann auf die Stecknadel neben „Cash Lister“. Dann steht das Symbol dauerhaft in der Leiste.

**Einstellungen direkt öffnen:** Ein Rechtsklick auf das Cash-Lister-Symbol und dann „Optionen“ öffnet die Seite „Cash Lister – Einstellungen“ (das ist Chrome-Standard für Erweiterungen mit Einstellungsseite). Einfacher geht es über den Eintrag „Einstellungen“ in der Seitenleiste.

## 3. Aufbau auf einen Blick

Von oben nach unten (am breiten Bildschirm):

```
+---------------+--------------------------------------------------------------+
| Seitenleiste  | Kopf: "Guten Tag, <Name>"          [Glocke]  [Kontofeld]     |
|               |       Wochentag, Datum · Server-Stand                        |
| Cash Lister   +--------------------------------------------------------------+
| Listing &     | (nur bei Bedarf) orange/rote Abo-Warnleiste                  |
| Tracking      +--------------------------------------------------------------+
|               | (nur wenn nicht angemeldet) Anmeldekarte                     |
| ARBEITEN      +--------------------------------------------------------------+
|  Dashboard    | Kennzahlen: Aktive Angebote | Produkte in der Datenbank |    |
|  Produkt-DB   |             Heute gelistet  | Tracker, letzter Lauf          |
|  CSV-Lister   +--------------------------------------------------------------+
|  Browser-L.   | Vorgänge: Produkte sammeln | CSV-Lister | Browser-Lister |    |
|  Tracker      |           Tracker                                            |
| AUSWERTEN     +--------------------------------------------------------------+
|  Verkaufs-Ü.  | Heute: Checkliste mit 4 Punkten                              |
|  Konkurrenz-S.+--------------------------------------------------------------+
| SYSTEM        | (nur mit Abrechnung) Karte "Dein Abo"                        |
|  Einstellungen|                                                              |
|               |                                                              |
| Server-Stand  |                                                              |
| Version 46.0  |                                                              |
+---------------+--------------------------------------------------------------+
```

In einem schmaleren Fenster rücken die Kennzahlen und Vorgänge erst in zwei Spalten, in einem sehr schmalen Fenster untereinander.

**Ist das Chrome-Fenster schmal** (etwa ein halber Bildschirm oder weniger), ändert sich der Aufbau stärker:

- Die Seitenleiste steht dann **oben** als waagerechte Reihe von Knöpfen (bei Bedarf seitlich verschiebbar), nicht mehr links.
- Die Gruppenüberschriften, der **Server-Stand** und die **Versionsnummer** der Seitenleiste sind dann **ausgeblendet**. Willst du sie sehen, zieh das Fenster breiter oder maximiere es.
- Das Kontofeld zeigt nur noch den runden Kreis mit deinen Initialen.
- Die Anmeldekarte steht einspaltig (Formular oben, Einrichtungsdatei darunter).

## 4. Die Seitenleiste

Die Seitenleiste steht links auf **jeder** Seite von Cash Lister: Dashboard, Produkt-Datenbank, CSV-Lister, Browser-Lister (auch auf dessen Statusbericht), Tracker, Verkaufs-Übersicht, Konkurrenz-Scanner und Einstellungen. Sie sieht überall gleich aus.

### 4.1 Marke und Module

Ganz oben steht das Logo mit „**Cash Lister**“ und darunter „Listing & Tracking“.

Darunter die Module, in drei Gruppen:

| Gruppe | Eintrag | Öffnet |
|---|---|---|
| **Arbeiten** | „Dashboard“ | diese Startseite |
| | „Produkt-Datenbank“ | die Seite „Cash Lister – Produkt-Datenbank“ (siehe `produkte-finden-und-datenbank.md`) |
| | „CSV-Lister“ | die Seite „Cash Lister – CSV-Lister“ (siehe `produktuebersicht-und-csv-lister.md`) |
| | „Browser-Lister“ | die Seite „Cash Lister – Browser-Lister“ (früher „Bulk-Lister“, siehe `listen-auf-ebay.md`) |
| | „Tracker“ | die Seite „Cash Lister – Tracker“ (früher „CSV Tracker“, siehe `tracker.md`) |
| **Auswerten** | „Verkaufs-Übersicht“ | die Seite „Cash Lister – Verkaufs-Übersicht“ (siehe `produktuebersicht-und-csv-lister.md`) |
| | „Konkurrenz-Scanner“ | die Seite „Cash Lister – Konkurrenz-Scanner“ (siehe `produkte-finden-und-datenbank.md`) |
| **System** | „Einstellungen“ | die Seite „Cash Lister – Einstellungen“ (siehe `einstellungen.md`) |

- Der Eintrag der Seite, auf der du gerade bist, ist **hervorgehoben**. Klickst du ihn an, springt die Seite nur nach oben.
- Jeder andere Eintrag öffnet das Modul in einem **eigenen Tab** oder springt in den schon offenen Tab (siehe [Abschnitt 5](#5-module-öffnen-eigener-tab-kein-zweiter-tab)).
- Auf dem Statusbericht des Browser-Listers ist kein Eintrag hervorgehoben.
- **CSV-Lister:** In Version 46.0 steht der Eintrag für alle Kunden in der Leiste. Fehlt er bei dir, frag den Betreiber.

### 4.2 Gesperrte Einträge ohne Anmeldung

Bist du **nicht angemeldet**, ist dein **Zugang abgeschaltet** oder ist dein **Abo gesperrt**, sind alle Einträge **ausgegraut und nicht anklickbar**, außer:

- „Dashboard“ (dort meldest du dich an),
- „Einstellungen“ (die gehen immer).

Nach der Anmeldung werden die Einträge von selbst wieder anklickbar (spätestens nach etwa 15 Sekunden, auf dem Dashboard sofort).

### 4.3 Server-Stand unten in der Leiste

Unten in der Leiste steht ein kleiner farbiger Punkt mit einem Text und darunter ein bis zwei kleine Zeilen. Beim allerersten Aufbau steht kurz „Verbindung wird geprüft …“. Danach gibt es diese Zustände:

| Punkt | Text | Zweite Zeile | Dritte Zeile | Bedeutung |
|---|---|---|---|---|
| grün | „Server verbunden“ | „angemeldet als <Name>“ | „Produkt-Vergabe aktiv“ | Alles in Ordnung. Die Extension hat deine Anmeldung vor Kurzem erfolgreich beim Server geprüft. |
| orange | „Server nicht erreicht“ | „antwortet nicht seit heute 14:05“ oder „zuletzt erreicht heute 13:30“ (oder leer) | „Lister nehmen keine Produkte“ | Der Server hat zuletzt nicht geantwortet. Siehe [Abschnitt 15](#15-wenn-der-server-nicht-erreichbar-ist). |
| rot | „Zugang abgeschaltet“ | „angemeldet als <Name>“ | „Produkt-Vergabe aus“ | Der Betreiber hat deinen Zugang abgeschaltet. Siehe [9.6](#96-zugang-abgeschaltet). |
| rot | „Abo gesperrt“ | „Details im Dashboard“ | „Produkt-Vergabe aus“ | Dein Zugang ist wegen des Abos gesperrt. Siehe [9.7](#97-abo-gesperrt). |
| grau | „Nicht angemeldet“ | (leer) | „Produkt-Vergabe aus“ | Du bist nicht angemeldet. Anmelden im Dashboard ([Abschnitt 9](#9-die-anmeldekarte)). |

Was die Zeilen bedeuten:

- **„Produkt-Vergabe“** ist die Funktion, die verhindert, dass zwei Kunden von Cash Lister dasselbe Amazon-Produkt listen. Sie braucht Anmeldung und Server. Mehr dazu in `listen-auf-ebay.md` und `produkte-finden-und-datenbank.md`.
- **„Lister nehmen keine Produkte“** heißt: Solange der Server nicht antwortet, nehmen Browser-Lister und CSV-Lister keine neuen Produkte aus der Produkt-Datenbank. Der Browser-Lister wartet und macht von selbst weiter, sobald der Server wieder antwortet.

Woher die Leiste das weiß: Die Extension prüft regelmäßig im Hintergrund, beim Chrome-Start und bei jedem Öffnen oder Neuladen des Dashboards, ob deine Anmeldung noch gilt. „Server nicht erreicht“ erscheint,

- sobald eine Anfrage an die Produkt-Datenbank am Server scheitert (sofort), oder
- wenn die letzte erfolgreiche Prüfung länger als etwa eine Stunde her ist.

Die Leiste selbst fragt keinen Server. Sie liest nur, was die Extension im Hintergrund zuletzt erfahren hat, und frischt sich etwa alle 15 Sekunden auf, solange die Seite sichtbar ist.

### 4.4 Versionsnummer

Ganz unten in der Leiste steht die Version, z. B. „**Version 46.0**“. Das ist die Version, die gerade in Chrome geladen ist. Diese Nummer brauchst du, wenn du dich beim Betreiber meldest. Früher stand sie oben im Popup (z. B. „v45.4“).

Siehst du keine Versionsnummer, ist das Fenster zu schmal (die Leiste steht dann oben, siehe [Abschnitt 3](#3-aufbau-auf-einen-blick)). Zieh das Fenster breiter oder maximiere es.

## 5. Module öffnen: eigener Tab, kein zweiter Tab

Egal ob du in der Seitenleiste, auf einer Karte unter „Vorgänge“ oder auf einen Hinweis in der Glocke klickst:

1. Ist das Modul **noch nicht offen**, öffnet es sich in einem **neuen Tab**.
2. Ist das Modul **schon offen** (auch in einem anderen Chrome-Fenster), **springt** Cash Lister zu diesem Tab und holt das Fenster nach vorn. Es öffnet sich **kein zweiter Tab** desselben Moduls.

Warum das so ist: Ein Lauf von Tracker oder Browser-Lister lebt nur, solange sein Tab offen ist. Zwei Tabs desselben Moduls würden sich gegenseitig den gespeicherten Stand überschreiben. Deshalb führt jeder Klick immer zu dem einen offenen Tab.

Tipp: Schließe den Tab eines laufenden Trackers oder Browser-Listers nicht. Das Dashboard zeigt dann „unterbrochen“ bzw. „Tab geschlossen“ (siehe [Abschnitt 11](#11-vorgänge-die-modulkarten)).

## 6. Der Kopf: Begrüßung und Statuszeile

Ganz oben auf dem Dashboard steht eine große Überschrift und darunter eine kleine Zeile.

**Überschrift (Begrüßung):**

- Angemeldet: „Guten Morgen, <Name>“ (vor 11 Uhr), „Guten Tag, <Name>“ (11 bis 18 Uhr) oder „Guten Abend, <Name>“ (ab 18 Uhr). Der Name ist der Anzeigename deines Zugangs (sonst dein Benutzername).
- Nicht angemeldet, abgeschaltet oder Abo gesperrt: „Willkommen bei Cash Lister“.

**Kleine Zeile darunter:** das heutige Datum mit Wochentag und der Server-Stand, z. B. „Montag, 26. Oktober · Server verbunden“. Mögliche Server-Angaben:

| Angabe | Bedeutung |
|---|---|
| „Server verbunden“ | Angemeldet, Server antwortet. |
| „Server nicht erreicht“ | Angemeldet, aber der Server hat zuletzt nicht geantwortet ([Abschnitt 15](#15-wenn-der-server-nicht-erreichbar-ist)). |
| „Zugang abgeschaltet“ | Der Betreiber hat den Zugang abgeschaltet ([9.6](#96-zugang-abgeschaltet)). |
| „Abo gesperrt“ | Zugang wegen des Abos gesperrt ([9.7](#97-abo-gesperrt)). |
| „nicht angemeldet“ | Du bist nicht angemeldet. |

Rechts im Kopf stehen die **Glocke** ([Abschnitt 7](#7-die-glocke-hinweise)) und das **Kontofeld** ([Abschnitt 8](#8-das-kontofeld-und-abmelden)).

## 7. Die Glocke (Hinweise)

Der runde Knopf mit der **Glocke** oben rechts sammelt Hinweise, die deine Aufmerksamkeit brauchen.

- **Kleiner Punkt an der Glocke:** Es gibt mindestens einen Hinweis. Ist der Punkt **rot**, ist mindestens ein ernster Hinweis dabei (z. B. Tracker angehalten, Zahlung überfällig). Sonst ist er türkis.
- **Klick auf die Glocke** klappt die Liste auf. Noch ein Klick, ein Klick daneben oder die Taste Esc klappt sie wieder zu.
- **Keine Hinweise:** Dann steht „Keine Hinweise – alles in Ordnung.“
- **Ohne Anmeldung** (und ebenso bei abgeschaltetem Zugang oder Abo-Sperre) zeigt die Glocke keine Hinweise und auch keinen Punkt; aufgeklappt steht dann ebenfalls „Keine Hinweise – alles in Ordnung.“. Das heißt nicht, dass alles in Ordnung ist: Schau in die Anmeldekarte ([Abschnitt 9](#9-die-anmeldekarte)).

Manche Hinweise kann man anklicken. Dann öffnet der Klick das passende Modul (oder springt in seinen Tab) bzw. die Zahlungsseite. Alle möglichen Hinweise, in der Reihenfolge, in der sie erscheinen:

| Überschrift | Text darunter | Farbe | Klick führt zu |
|---|---|---|---|
| „Zahlung offen“, „Zahlung überfällig“, „Erste Zahlung fehlgeschlagen“, „Abo gesperrt“, „Abo beendet“ oder „Noch kein Abo eingerichtet“ | wie in der Abo-Warnleiste ([14.2](#142-die-warnleiste-oben)) | orange oder rot | Zahlungsseite in neuem Tab (wenn bekannt), sonst nichts |
| „Server nicht erreicht“ | „Antwortet nicht seit heute 14:05.“ bzw. „Zuletzt erreicht heute 13:30.“, dann „Ohne Server nehmen die Lister keine Produkte aus der Datenbank – der Browser-Lister wartet und macht danach von selbst weiter.“ | orange | nichts |
| „<Gerätename> meldet sich seit 12 Min. nicht“ | „Letzte Meldung heute 14:05. Läuft dort Chrome mit Cash Lister und Internet?“ | orange | nichts (siehe [Abschnitt 13](#13-server-geräte-server-modus-im-dashboard)) |
| „Tracker angehalten“ | „Zu viele Artikel ohne Ergebnis – im Tracker nachsehen.“ | rot | Tracker |
| „Lauf des Trackers unterbrochen“ | „Bei 370 von 1.000 – im Tracker fortsetzen.“ | orange | Tracker |
| „Tracker wartet“ | „Amazon hat kurz gesperrt, der Tracker macht danach von selbst weiter.“ | orange | Tracker |
| „Browser-Lister-Tab geschlossen“ | „Der Lauf endet nach dem aktuellen Produkt.“ bzw. während einer Pause der Zeitschaltung „Der Lauf endet nach der Pause.“ | orange | Browser-Lister |
| „CSV-Lister-Lauf unterbrochen“ | „Der Tab wurde geschlossen. Beim nächsten Öffnen räumt der CSV-Lister auf.“ | orange | CSV-Lister |
| „CSV-Lister: Hochladen fehlgeschlagen“ | der Fehlertext des CSV-Listers (gekürzt) | rot | CSV-Lister |
| „CSV-Lister angehalten“ | der Grund (gekürzt) | orange | CSV-Lister |
| „<Zahl> Produkte warten auf das eBay-Ergebnis“ | „Im CSV-Lister „Ergebnisse bei eBay abholen“.“ | neutral | CSV-Lister |
| „Einstellungen: zwei Geräte“ | „Ein anderes Gerät hat anders gesichert. Unter Einstellungen → Sicherung entscheiden, welcher Stand gilt.“ | orange | Einstellungen |
| „Einstellungen zu groß für die Sicherung“ | „<Zahl> KB – sie werden nicht auf dem Server gesichert.“ | orange | nichts |

Wichtig:

- Die Tracker-, Browser-Lister- und CSV-Lister-Hinweise betreffen **nur diesen PC**. Was auf Server-Geräten läuft, siehst du auf den Karten unter „Vorgänge“ ([Abschnitt 13](#13-server-geräte-server-modus-im-dashboard)).
- Was „Tracker angehalten“ (Notbremse), „Tracker wartet“ (Sperre durch Amazon) und „unterbrochen“ genau heißen und wie man weitermacht, steht in `tracker.md`.
- Was bei „Einstellungen: zwei Geräte“ zu tun ist, steht in `einstellungen.md` bzw. `konto-und-installation.md` (Reiter „Sicherung“).

## 8. Das Kontofeld und Abmelden

Das **Kontofeld** ist der längliche Knopf ganz rechts oben. Links darin ein runder Kreis mit deinen **Initialen** (die Anfangsbuchstaben deines Namens, höchstens zwei, z. B. „MM“ für „max.mustermann“), rechts dein Name und darunter eine kleine Zeile.

**Was im Kontofeld steht:**

| Zustand | Kreis | Name | Kleine Zeile |
|---|---|---|---|
| angemeldet | Initialen | dein Name | „angemeldet“ |
| Abmeldung läuft | Initialen | dein Name | „wird abgemeldet …“ |
| Abo gesperrt | „?“ oder Initialen | „Nicht angemeldet“ oder dein Name | „Abo gesperrt“ |
| Zugang abgeschaltet | Initialen | dein Name | „Zugang abgeschaltet“ |
| nicht angemeldet | „?“ | „Nicht angemeldet“ | (leer) |

**Klick auf das Kontofeld:**

- **Angemeldet:** Es klappt ein kleines Menü auf. Oben stehen dein Name und „Angemeldet · Server verbunden“ (bzw. „Angemeldet · Server nicht erreicht“). Darunter der Eintrag **„Abmelden“** mit dem Hinweis „Danach sperren sich die Module bis zur nächsten Anmeldung.“ Ein Klick daneben oder Esc schließt das Menü.
- **Nicht angemeldet, abgeschaltet oder Abo gesperrt:** Es klappt nichts auf. Der Klick setzt den Cursor ins Feld „Benutzername“ der Anmeldekarte (Tooltip „Zum Anmeldeformular“).

**Abmelden, Schritt für Schritt:**

1. Klick oben rechts auf das Kontofeld.
2. Klick im Menü auf „Abmelden“.
3. Läuft auf **diesem PC** gerade der Tracker, der Browser-Lister oder der CSV-Lister, fragt Chrome nach: „Gerade läuft auf diesem PC: Tracker, Browser-Lister. Nach dem Abmelden sperren sich die Module. Trotzdem abmelden?“ (die Liste nennt, was gerade läuft). Mit „Abbrechen“ bleibst du angemeldet, mit „OK“ geht es weiter.
4. Im Kontofeld steht kurz „wird abgemeldet …“.
5. Danach erscheint die Anmeldekarte, und die Module in der Seitenleiste sind ausgegraut.

Gut zu wissen:

- Nach dem Abmelden sperren sich die Module. Ein laufender Lauf auf diesem PC kann dann nicht normal weiterarbeiten. Melde dich deshalb nicht mitten in einem Lauf ab.
- Ist der Server beim Abmelden nicht erreichbar, meldet dich die Extension trotzdem auf diesem PC ab. Du hängst also nicht fest.
- Ist dieses Gerät als Server-Gerät eingerichtet ([Abschnitt 13](#13-server-geräte-server-modus-im-dashboard)), verschwindet es beim Abmelden aus den Dashboards deiner anderen Geräte.

## 9. Die Anmeldekarte

### 9.1 Wann sie erscheint

Die Anmeldekarte steht oben im Dashboard (unter dem Kopf), wenn

- du **nicht angemeldet** bist (Überschrift „Nicht angemeldet“),
- dein **Zugang abgeschaltet** ist (Überschrift „Zugang abgeschaltet“, orange) oder
- dein **Abo gesperrt** ist (Überschrift „Abo gesperrt“, rot).

Bist du angemeldet, ist die Karte weg.

Die Karte hat zwei Hälften:

- **Links:** Überschrift, Erklärtext und das Formular mit „Benutzername“, „Passwort“ und dem Knopf „Anmelden“. Der Erklärtext lautet normalerweise „Melde dich mit deinem Zugang an. Danach füllt sich diese Seite von selbst.“
- **Rechts:** „Einrichtungsdatei“ mit dem Text „Datei vom Betreiber bekommen? Sie bringt die Einstellungen und deinen Zugang mit und meldet dich gleich an.“, dem Knopf „Einrichtungsdatei einlesen“ und ganz unten einem Aufklapper „Server-Adresse (nur auf Ansage ändern)“.

### 9.2 Anmelden mit Benutzername und Passwort

1. Öffne das Dashboard (Klick auf das Cash-Lister-Symbol).
2. Trag in der Anmeldekarte links bei „Benutzername“ deinen Benutzernamen ein.
3. Trag bei „Passwort“ dein Passwort ein.
4. Klick auf „**Anmelden**“ (oder drück im Passwortfeld die Eingabetaste).
5. Unter dem Knopf steht „Melde an …“. Der Knopf ist so lange gesperrt.
6. **Geklappt:** Die Anmeldekarte verschwindet, das Passwortfeld wird geleert, oben steht „Guten Tag, <Name>“, in der Seitenleiste „Server verbunden“, und die Module sind anklickbar. Die Zahlen und Karten füllen sich innerhalb weniger Sekunden.
7. **Nicht geklappt:** Unter dem Knopf steht eine rote Meldung. Was sie bedeutet, steht in [9.5](#95-alle-meldungen-beim-anmelden).

Benutzername und Passwort bekommst du vom Betreiber. Du findest sie auch in deiner Einrichtungsdatei. Gib sie nicht weiter.

Was nach der Anmeldung nebenbei passiert (du musst nichts tun):

- Die Extension holt den Stand deines Abos (für die Karte „Dein Abo“).
- Sie kümmert sich um die Sicherung deiner Einstellungen auf dem Server. Bei einem frisch installierten Chrome-Profil holt sie eine vorhandene Sicherung zurück. Details stehen in `konto-und-installation.md`.
- Liegt auf diesem PC noch eine Produkt-Datenbank aus einer älteren Version, lädt sie diese in deine Produkt-Datenbank auf dem Server hoch ([10.2](#102-produkte-in-der-datenbank)).

### 9.3 Anmelden mit der Einrichtungsdatei

Die **Einrichtungsdatei** bekommst du vom Betreiber. Sie heißt `zugang.json` oder `leck-atakan-einrichtung-<dein Benutzername>.json`. Sie enthält Einstellungen und deinen Zugang (Benutzername und Passwort). **Gib sie nicht weiter.**

1. Öffne das Dashboard. Du musst abgemeldet sein, sonst ist die Anmeldekarte nicht da.
2. Klick in der rechten Hälfte der Anmeldekarte auf „**Einrichtungsdatei einlesen**“.
3. Wähle im Dateifenster deine Einrichtungsdatei aus (angeboten werden `.json`-Dateien).
4. Grün erscheint „<Zahl> Einstellungen übernommen – melde an …“. Benutzername und Passwort stehen jetzt links im Formular, und die Anmeldung startet von selbst.
5. Weiter wie in [9.2](#92-anmelden-mit-benutzername-und-passwort), ab Schritt 5.

Wichtig:

- Die Datei **überschreibt** die Einstellungen in diesem Chrome-Profil mit allem, was in der Datei steht.
- Enthält die Datei keine Zugangsdaten, steht dort „<Zahl> Einstellungen übernommen. Die Datei enthielt keine Zugangsdaten – bitte von Hand anmelden.“ Dann meldest du dich wie in [9.2](#92-anmelden-mit-benutzername-und-passwort) an.
- Stammt die Datei aus einer älteren Version und enthält sie noch eine Produktliste, lädt die Extension diese nach der Anmeldung in deine Produkt-Datenbank auf dem Server hoch.
- Bist du schon angemeldet, gibt es die Anmeldekarte nicht. Einstellungen aus einer Datei holst du dann unter Einstellungen → Reiter „Sicherung“ → „Einstellungen importieren“ (siehe `einstellungen.md` bzw. `konto-und-installation.md`).

Meldungen beim Einlesen:

| Meldung | Bedeutung | Was tun |
|---|---|---|
| „<Zahl> Einstellungen übernommen – melde an …“ | Datei gelesen, Anmeldung läuft. | Warten. |
| „<Zahl> Einstellungen übernommen. Die Datei enthielt keine Zugangsdaten – bitte von Hand anmelden.“ | Datei gelesen, aber ohne Benutzername/Passwort. | Von Hand anmelden. |
| „Die Datei ist kein gültiges JSON.“ | Die Datei ist beschädigt oder keine Einrichtungsdatei. | Richtige Datei wählen; im Zweifel den Betreiber um eine neue bitten. |
| „Das ist keine Einstellungsdatei.“ | Die Datei hat den falschen Inhalt. | Richtige Datei wählen. |
| „Import fehlgeschlagen: …“ | Chrome konnte die Einstellungen nicht speichern. | Chrome neu starten, noch einmal versuchen; sonst Betreiber. |

### 9.4 Server-Adresse (nur auf Ansage ändern)

Ganz unten in der rechten Hälfte der Anmeldekarte steht der Aufklapper „**Server-Adresse (nur auf Ansage ändern)**“. Klappst du ihn auf, siehst du ein Eingabefeld mit der Adresse, die gerade gilt (ist keine bekannt, steht dort grau „wird automatisch gesetzt“).

- **Ändere die Adresse nur, wenn der Betreiber es dir ausdrücklich sagt.** Normalerweise wird sie automatisch gesetzt.
- Eine Änderung gilt, sobald du das Feld verlässt.
- Hast du die Adresse aus Versehen geändert: Feld ganz leeren und daneben klicken. Dann gilt wieder die Voreinstellung.
- Eine Einrichtungsdatei kann die Adresse ebenfalls mitbringen.
- Dieselbe Adresse findest du auch unter Einstellungen → Reiter „eBay & Rahmenbedingungen“ → Karte „Server & Produkt-Vergabe“ → „Server-Adresse“, dort mit dem Knopf „Verbindung prüfen“ (siehe `einstellungen.md`). Die Einstellungen öffnen sich auch ohne Anmeldung.

Die Adresse selbst nennt diese Hilfe nicht. Fragt ein Kunde danach, verweise ihn an den Betreiber.

### 9.5 Alle Meldungen beim Anmelden

Die Meldungen stehen unter dem Knopf „Anmelden“; Fehlermeldungen sind rot.

| Meldung (wörtlich) | Bedeutung | Was tun |
|---|---|---|
| „Melde an …“ | Die Anmeldung läuft (grau, keine Fehlermeldung). | Warten, bis zu etwa 20 Sekunden. |
| „Name oder Passwort falsch.“ | Benutzername oder Passwort stimmt nicht. Aus Sicherheitsgründen sagt der Server nicht, welches von beiden. | Groß- und Kleinschreibung prüfen, keine Leerzeichen am Anfang oder Ende. Am sichersten mit der Einrichtungsdatei anmelden ([9.3](#93-anmelden-mit-der-einrichtungsdatei)). Klappt es nicht, Betreiber fragen. |
| „Name und Passwort noetig“ | Eines der beiden Felder war leer (so geschrieben, mit „oe“). | Beide Felder ausfüllen. |
| „Zu viele Fehlversuche. Bitte <Zahl> Sekunden warten.“ (oder „Zu viele Fehlversuche. Bitte kurz warten.“) | Nach mehreren falschen Versuchen sperrt der Server kurz. | Die genannte Zeit abwarten, dann mit richtigen Daten noch einmal. |
| „Dieser Zugang ist abgeschaltet.“ | Der Betreiber hat deinen Zugang abgeschaltet. | Beim Betreiber melden ([9.6](#96-zugang-abgeschaltet)). |
| „Anmeldung abgelehnt: Abo gesperrt.“ (gleichzeitig wechselt die Überschrift der Karte auf „Abo gesperrt“, und darunter steht der Text vom Server, z. B. „Abo abgelaufen – bitte die Zahlung erneuern oder beim Betreiber melden.“) | Benutzername und Passwort stimmen, aber dein Zugang ist wegen des Abos gesperrt. | Siehe [9.7](#97-abo-gesperrt). |
| „Deine Version der Extension ist veraltet und wird nicht mehr unterstuetzt. Bitte melde dich beim Betreiber - du bekommst dann die neue Version.“ | Deine installierte Version ist zu alt, um sich anzumelden. | Siehe [9.8](#98-veraltete-version). |
| „Server nicht erreichbar (…). Adresse prüfen oder später erneut versuchen.“ | Der Server hat nicht geantwortet. In der Klammer steht die Server-Adresse, die gerade gilt. | Internet prüfen, ein paar Minuten warten, noch einmal. Server-Adresse nur auf Ansage ändern ([9.4](#94-server-adresse-nur-auf-ansage-ändern)). Hält es an, Betreiber fragen. |
| „Keine Antwort vom Hintergrunddienst – bitte noch einmal versuchen.“ | Nach 30 Sekunden kam keine Antwort von der Extension im Hintergrund. Oft läuft nach einem Update noch der alte Hintergrunddienst. | Noch einmal versuchen. Hilft das nicht: Hintergrunddienst aktualisieren (Chrome komplett neu starten, sonst `chrome://extensions` → bei Cash Lister „Neu laden“), siehe `konto-und-installation.md`. |
| „Keine Server-Adresse hinterlegt. Bitte eintragen (Einstellungen → eBay → „Server & Produkt-Vergabe“).“ | Es ist keine Server-Adresse bekannt. Das sollte normalerweise nicht vorkommen. Mit „eBay“ ist der Reiter „eBay & Rahmenbedingungen“ gemeint. | Beim Betreiber melden und nach der richtigen Adresse bzw. einer Einrichtungsdatei fragen. |
| „Anmeldung fehlgeschlagen (HTTP <Zahl>).“ oder ein anderer Text vom Server | Ein anderer Fehler beim Server. | Später noch einmal; sonst Betreiber mit dem genauen Wortlaut. |

### 9.6 Zugang abgeschaltet

Hat der Betreiber deinen Zugang abgeschaltet, siehst du:

- in der Anmeldekarte die orange Überschrift „Zugang abgeschaltet“ und den Text „Zugang abgeschaltet – bitte beim Betreiber melden. Mit einem anderen Zugang kannst du dich hier neu anmelden.“,
- im Kontofeld deinen Namen mit „Zugang abgeschaltet“,
- in der Seitenleiste einen roten Punkt mit „Zugang abgeschaltet“ und „Produkt-Vergabe aus“,
- alle Module außer Dashboard und Einstellungen ausgegraut.

Was tun: Beim Betreiber melden. Freischalten kann nur er. Diese Hilfe kann dazu nichts zusagen.

### 9.7 Abo gesperrt

Ist dein Zugang wegen des Abos gesperrt (z. B. weil eine Zahlung fehlt), siehst du:

- in der Anmeldekarte die rote Überschrift „**Abo gesperrt**“ und darunter den Text vom Server, z. B. „Abo abgelaufen – bitte die Zahlung erneuern oder beim Betreiber melden.“ (fehlt der Text, steht dort „Bitte die Zahlung erneuern oder beim Betreiber melden.“),
- wenn die Extension deine Zahlungsseite kennt: den Knopf „**Zur Zahlungsseite**“ und daneben „Nach der Zahlung hier wieder anmelden.“,
- in der Kopfzeile „Abo gesperrt“, im Kontofeld „Abo gesperrt“,
- in der Seitenleiste einen roten Punkt mit „Abo gesperrt“, „Details im Dashboard“ und „Produkt-Vergabe aus“,
- alle Module außer Dashboard und Einstellungen ausgegraut.

So kommst du wieder rein:

1. Klick auf „Zur Zahlungsseite“ (öffnet sich in einem neuen Tab). Fehlt der Knopf, frag den Betreiber nach deinem persönlichen Zahlungslink.
2. Bezahle bzw. richte dort das Abo ein.
3. Geh zurück zum Dashboard und **melde dich neu an** ([9.2](#92-anmelden-mit-benutzername-und-passwort)).
4. Klappt die Anmeldung noch nicht und kommt wieder „Abo gesperrt“, ist die Zahlung vermutlich noch nicht beim Betreiber angekommen. Warte ein paar Minuten und versuche es noch einmal. Hält es an, beim Betreiber melden. Wie lange die Freischaltung genau dauert, ist nicht sicher belegt (siehe [14.6](#146-sperre-und-freischaltung-nach-der-zahlung)).

Die Sperre bleibt in der Anzeige (Anmeldekarte, Kontofeld, Seitenleiste) stehen, bis du dich erfolgreich neu anmeldest. Solange gesperrt ist, gibt es im Kontofeld kein Menü mit „Abmelden“.

### 9.8 Veraltete Version

Ist deine installierte Version zu alt, lehnt der Server die Anmeldung ab. Du siehst dann: „Deine Version der Extension ist veraltet und wird nicht mehr unterstuetzt. Bitte melde dich beim Betreiber - du bekommst dann die neue Version.“ Warst du schon angemeldet, wirst du bei der nächsten Prüfung abgemeldet, und das Dashboard zeigt „Nicht angemeldet“. Den Grund (den Text oben) siehst du in diesem Fall erst, wenn du dich neu anmelden willst.

Das Aktualisieren mit `update.bat` funktioniert auch dann, wenn sich die Extension wegen der alten Version nicht mehr anmelden kann.

Was tun:

1. Die Extension mit `update.bat` aktualisieren (auf dem Mac mit `update.command`), siehe `konto-und-installation.md`.
2. **Chrome komplett neu starten**, damit auch der Hintergrunddienst die neue Version lädt. Hilft das nicht: `chrome://extensions` öffnen und bei Cash Lister auf „Neu laden“ (runder Pfeil) klicken.
3. Unten in der Seitenleiste prüfen, ob jetzt die neue „Version …“ steht.
4. Neu anmelden.
5. Kommt die Meldung trotzdem, beim Betreiber melden.

**Nicht sicher belegt:** Welche Version mindestens nötig ist, legt der Betreiber fest. Das weiß diese Hilfe nicht sicher. Frag den Betreiber.

## 10. Die vier Kennzahlen

Unter dem Kopf stehen vier Kacheln mit großen Zahlen. Ein „…“ mit „wird geladen“ heißt: Die Zahl kommt gleich. Ein „–“ heißt: Die Zahl ist gerade nicht bekannt (der Grund steht darunter).

### 10.1 Aktive Angebote

**Was die Zahl ist:** wie viele aktive Angebote dein eBay-Shop hat.

**Woher sie kommt:** aus einem von zwei Berichten auf **diesem PC**, je nachdem, welcher neuer ist:

| Kleine Zeile darunter | Quelle |
|---|---|
| „laut Tracker · Bericht heute 16:05“ | Der Angebotsbericht, den der Tracker auf diesem PC zuletzt eingelesen hat. Gezählt werden alle Zeilen des Berichts, egal welcher Filter im Tracker eingestellt ist. Die Zeit ist der Zeitpunkt des Einlesens. |
| „laut Verkaufs-Übersicht · Stand 24.10.2026“ | Der Bericht, den du zuletzt von Hand in die Verkaufs-Übersicht eingelesen hast. Das Datum ist das Datum des Berichts. |
| „kommt mit dem nächsten Lauf des Trackers“ (Zahl „–“) | Es gibt auf diesem PC noch keinen der beiden Berichte. |

Gut zu wissen:

- Die Zahl ist nur so aktuell wie der Bericht. Neue oder beendete Angebote seit dem Bericht sind nicht drin.
- Läuft dein Tracker nur auf einem Server-Gerät, steht auf deinem normalen PC hier eventuell „–“. Das ist normal: Diese Kachel liest nur Berichte von diesem PC.

### 10.2 Produkte in der Datenbank

**Was die Zahl ist:** wie viele Produkte in deiner **Produkt-Datenbank** liegen. Die Produkt-Datenbank liegt seit Version 46.0 **je Konto auf dem Server**. Alle Geräte, auf denen du mit demselben Zugang angemeldet bist, sehen dieselbe Liste und dieselbe Zahl.

**Kleine Zeile darunter:**

| Text | Bedeutung |
|---|---|
| „bereit zum Listen“ | Alle Produkte sind frei, keines ist gerade in Arbeit. |
| „250 bereit · 30 in Arbeit“ | 250 Produkte sind frei. 30 hat gerade ein Lister (Browser-Lister oder CSV-Lister, auf irgendeinem deiner Geräte) entnommen und arbeitet daran. |
| „leer – Produkte sammeln“ | Die Datenbank ist leer. Sammle Produkte (siehe `produkte-finden-und-datenbank.md`). |
| „1.200 werden noch auf den Server übertragen“ (Zahl „0“) | Die alte Produktliste dieses PCs wird gerade zum ersten Mal auf den Server übertragen. Die Liste ist nicht leer, sie ist nur noch unterwegs. |
| „… · 200 noch zu übertragen“ (am Ende angehängt) | Ein Teil der alten Liste dieses PCs ist noch nicht auf dem Server. Das läuft von selbst. |
| „Server nicht erreichbar“ (Zahl „–“) | Der Server antwortet nicht. Die Zahl ist unbekannt, die Datenbank ist **nicht** leer. Siehe [Abschnitt 15](#15-wenn-der-server-nicht-erreichbar-ist). |
| „nach der Anmeldung sichtbar“ (Zahl „–“) | Du bist nicht angemeldet. |
| „Sitzung abgelaufen – bitte im Dashboard neu anmelden.“ (Zahl „–“) | Deine Anmeldung gilt nicht mehr. Kurz darauf erscheint die Anmeldekarte. Neu anmelden. |
| „Zugang abgeschaltet – bitte beim Betreiber melden.“ | Zugang abgeschaltet ([9.6](#96-zugang-abgeschaltet)). |
| „Abo gesperrt – bitte im Dashboard nachsehen.“ | Abo gesperrt ([9.7](#97-abo-gesperrt)). |
| „Nicht angemeldet – bitte im Dashboard anmelden.“ | Nicht angemeldet. |
| „Stand nicht verfügbar“ | Die Extension im Hintergrund hat (noch) nicht geantwortet. Kurz warten; bleibt es so, Hintergrunddienst aktualisieren ([Abschnitt 19](#19-probleme-und-lösungen)). |

Die vier Texte „Sitzung abgelaufen …“, „Zugang abgeschaltet …“, „Abo gesperrt …“ und „Nicht angemeldet …“ stehen meist nur wenige Sekunden da: Sobald die Extension im Hintergrund die Anmeldung neu geprüft hat, wechselt das Dashboard in den passenden Zustand (Anmeldekarte), und unter der Zahl steht dann „nach der Anmeldung sichtbar“.

**Was „in Arbeit“ heißt:** Ein Lister hat das Produkt aus der Datenbank genommen, um es zu listen. Solange es in Arbeit ist, nimmt kein anderes deiner Geräte dasselbe Produkt. Fällt ein Gerät aus, wird das Produkt von selbst wieder frei. Wie lange, zeigt die Produkt-Datenbank in der Spalte „In Arbeit“ an der Uhrzeit hinter „bis“. Cash Lister verlangt dabei beim Browser-Lister etwa 30 Minuten (laufend verlängert, solange er arbeitet), beim CSV-Lister etwa 1 Stunde bzw. bis zu 7 Tage für Produkte, die schon in einer hochgeladenen Datei stehen (`references/produkte-finden-und-datenbank.md`, Abschnitt 10.9). **Nicht sicher belegt:** ob der Server diese Zeiten in jedem Fall genau so übernimmt – bei Fragen an den Betreiber wenden.

**Erste Übertragung:** Beim ersten Start von Version 46.0 lädt die Extension die alte Produktliste dieses PCs von selbst auf den Server hoch (Anmeldung nötig). Du musst nichts tun. Während das läuft, siehst du die Texte „werden noch auf den Server übertragen“ bzw. „noch zu übertragen“.

Die Zahl wird etwa alle 30 Sekunden neu geholt.

### 10.3 Heute gelistet

**Was die Zahl ist:** wie viele Angebote **heute** (ab Mitternacht, Uhrzeit dieses PCs) erfolgreich gelistet wurden, und zwar auf **diesem PC und auf deinen Server-Geräten** zusammen ([Abschnitt 13](#13-server-geräte-server-modus-im-dashboard)).

**Kleine Zeile darunter**, z. B. „Browser-Lister 30 · CSV-Lister 12 · 2 fehlgeschlagen · davon 20 auf Server-1“:

- „Browser-Lister <Zahl>“: heute mit dem Browser-Lister gelistet.
- „CSV-Lister <Zahl>“: heute mit dem CSV-Lister gelistet.
- „<Zahl> fehlgeschlagen“: Fehlschläge des Browser-Listers plus von eBay abgelehnte Zeilen des CSV-Listers (nur wenn es welche gab).
- „davon <Zahl> auf <Gerätename>“ bzw. „davon <Zahl> auf 2 anderen Geräten“: so viel davon kam von Server-Geräten.

**Die kleine Kurve** in der Kachel zeigt die gelisteten Angebote der letzten 14 Tage (rechts ist heute).

Gut zu wissen:

- Jedes Gerät zählt nur, was es selbst gelistet hat. Es wird nichts doppelt gezählt.
- Ein zweiter normaler PC, der **nicht** als Server-Gerät eingerichtet ist, wird hier **nicht** mitgezählt. Er meldet seinen Stand nicht.

### 10.4 Tracker, letzter Lauf

**Was die Kachel zeigt:** den Stand des Trackers, mit einem Fortschrittsbalken. Sie zeigt denselben Lauf wie die Karte „Tracker“ unter „Vorgänge“ ([11.5](#115-karte-tracker)), also den wichtigsten Stand von diesem PC und deinen Server-Geräten. Kommt der Stand von einem Server-Gerät, steht am Ende „· auf <Gerätename>“.

| Große Zahl | Kleine Zeile | Balken | Bedeutung |
|---|---|---|---|
| „–“ | „noch kein Lauf seit dem Update“ | leer | Seit dem Update auf das neue Dashboard hat der Tracker noch keinen Lauf gemacht. |
| „37 %“ | „370 von 1.000 geprüft“ | läuft mit | Der Tracker läuft gerade. |
| „37 %“ | „370 von 1.000 geprüft · wartet“ | läuft mit | Der Tracker wartet nach einer kurzen Sperre durch Amazon und macht dann von selbst weiter. |
| „25“ | „geändert hochgeladen · heute 06:12“ | grün, voll | Lauf fertig, 25 geänderte Angebote wurden zu eBay hochgeladen. |
| „1.000“ | „geprüft, nicht hochgeladen · heute 06:12“ | grün, voll | Lauf fertig, es wurde nichts hochgeladen. |
| „37 %“ | „pausiert bei 370 von 1.000“ | orange | Du hast den Lauf pausiert. |
| „37 %“ | „angehalten bei 370 von 1.000“ | orange | Die Notbremse des Trackers hat den Lauf angehalten (zu viele Artikel ohne Ergebnis oder 200 in Folge nicht kaufbar). |
| „37 %“ | „unterbrochen bei 370 von 1.000“ | orange | Der Lauf lief noch, aber der Tracker-Tab ist zu. Ohne Tab lebt kein Lauf. |
| „37 %“ | „keine Meldung seit 12 Min. · 370 von 1.000 · auf Server-1“ | orange | Das Server-Gerät hat sich seit mehr als 5 Minuten nicht gemeldet. Ob der Lauf dort noch lebt, ist unklar. |

Wie du einen pausierten, angehaltenen oder unterbrochenen Lauf fortsetzt, steht in `tracker.md`.

## 11. Vorgänge (die Modulkarten)

Unter den Kennzahlen steht der Abschnitt „**Vorgänge**“ mit großen Karten für die Module, die etwas tun: „Produkte sammeln“, „CSV-Lister“, „Browser-Lister“ und „Tracker“.

Rechts neben der Überschrift steht klein, worauf sich die Karten beziehen:

- „auf diesem PC · ein Klick öffnet das Modul“ (ohne Server-Geräte),
- „auf diesem PC und Server-1 · ein Klick öffnet das Modul auf diesem PC“ bzw. „auf diesem PC und 3 weiteren Geräten · …“ (mit Server-Geräten, siehe [Abschnitt 13](#13-server-geräte-server-modus-im-dashboard)).

**Ein Klick auf eine Karte öffnet das Modul** auf diesem PC (oder springt in seinen offenen Tab). Ohne Anmeldung sind die Karten ausgegraut und nicht anklickbar.

### 11.1 Aufbau einer Karte

Jede Karte hat vier Teile:

1. **Oben links** ein farbiges Symbol, **oben rechts** ein farbiges Schild (Marker) mit dem Zustand, z. B. „bereit“ oder „läuft · 12 von 100“. Die Farben stehen in [Abschnitt 17](#17-farben-und-zeichen).
2. **Name und Zweck**, z. B. „Tracker“ und „Preise und Bestand der aktiven Angebote mit Amazon abgleichen und zu eBay hochladen.“
3. **Stand-Zeile** mit Uhr-Symbol: was zuletzt passiert ist.
4. **Unterste Zeile** (Tab-Zeile) mit Fenster-Symbol:
   - „Klick öffnet: <Modulname>“: Das Modul ist auf diesem PC nicht offen, ein Klick öffnet es.
   - „<Modulname> ist offen – Klick springt hin“: Das Modul ist schon offen, ein Klick springt in den Tab.
   - Mit Server-Geräten steht hier stattdessen, **woher** der angezeigte Stand kommt ([Abschnitt 13](#13-server-geräte-server-modus-im-dashboard)).

### 11.2 Karte Produkte sammeln

Zweck auf der Karte: „Von der Amazon-Suche, aus Schaufenstern oder per Link in die Produkt-Datenbank.“ Ein Klick öffnet die **Produkt-Datenbank** (siehe `produkte-finden-und-datenbank.md`).

| Marker | Farbe | Bedeutung |
|---|---|---|

## 13. Server-Geräte (Server-Modus) im Dashboard

**Was ein Server-Gerät ist:** ein weiterer Rechner mit Chrome und Cash Lister, auf dem Tracker und Browser-Lister laufen, z. B. ein gemieteter Server. Damit du dessen Stand auf deinen anderen Geräten siehst, schaltest du **auf dem Server-Gerät** den Server-Modus ein. Er meldet dann etwa jede Minute seinen Stand.

**Einschalten (auf dem Server-Gerät):**

1. Seitenleiste → „Einstellungen“.
2. Reiter „eBay & Rahmenbedingungen“.
3. Karte „Server-Modus“ (daneben klein „z. B. ein gemieteter Server“): Schalter „**Dieses Gerät ist ein Server**“ einschalten (Hinweis darunter: „meldet etwa jede Minute seinen Stand · nur mit Anmeldung“).
4. Bei „**Gerätename**“ einen Namen eintragen, z. B. „Server-1“ (höchstens 40 Zeichen). Ab Werk steht dort „Server“. Leerst du das Feld, setzt die Seite wieder „Server“ ein.

Schalter und Name wirken sofort, sobald du sie änderst; ein Klick auf „Speichern“ ist dafür nicht nötig. Der Schalter gilt nur für dieses eine Gerät (Hinweis in der Karte: „Gilt nur für dieses Gerät.“); er wird nicht mit den Einstellungen gesichert oder exportiert. Das Server-Gerät muss mit **demselben Zugang** angemeldet sein wie deine anderen Geräte. Mehr zur Einstellung in `einstellungen.md`.

**Was du auf deinen anderen Geräten im Dashboard siehst:**

- **Vorgänge:** Die Karten „Browser-Lister“ und „Tracker“ zeigen den **wichtigsten Stand** aus „dieser PC + Server-Geräte“. Ein laufender Lauf geht vor; sonst der zuletzt aktive; bei Gleichstand dieser PC.
- **Die unterste Zeile** sagt dann, woher der Stand kommt:
  - mit Raster-Symbol: „Dieser PC · Tab offen – Klick springt hin“ bzw. „Dieser PC · Klick öffnet: Tracker“,
  - mit Wolken-Symbol: „Server-1 · letzte Meldung vor 40 s“ (bzw. „gerade eben“),
  - laufen mehrere: am Ende „· + 1 weitere“. Fährst du mit der Maus über die Karte, nennt ein Tooltip die anderen („Läuft auch auf: …“).
  - Ist die Zeile **orange**, hat sich das Server-Gerät seit mehr als 5 Minuten nicht gemeldet.
- **Ein Klick öffnet trotzdem das Modul auf diesem PC**, nicht auf dem Server-Gerät (Tooltip: „Stand von Server-1 – ein Klick öffnet Tracker auf diesem PC“). Steuern musst du den Lauf auf dem Server-Gerät selbst, z. B. per Fernzugriff.
- **„Heute gelistet“** und die Checkliste zählen die Server-Geräte mit ([10.3](#103-heute-gelistet), [Abschnitt 12](#12-die-checkliste-heute)).
- **„Tracker, letzter Lauf“** zeigt denselben Stand wie die Tracker-Karte, mit „· auf <Gerätename>“.
- **Glocke:** Meldet sich ein Server-Gerät seit mehr als 5 Minuten nicht, erscheint „<Gerätename> meldet sich seit <Zeit> nicht“ mit „Letzte Meldung …. Läuft dort Chrome mit Cash Lister und Internet?“

**Nicht** mit Server-Geräten verbunden sind:

- die Kachel „Aktive Angebote“ (nur Berichte dieses PCs),
- die Tracker-, Browser-Lister- und CSV-Lister-Hinweise in der Glocke (nur dieser PC),
- die Karte „Produkte sammeln“ (die Produkt-Datenbank gehört ohnehin dem ganzen Konto).

Weitere Regeln:

- Das Dashboard **auf dem Server-Gerät selbst** zeigt dessen eigenen Stand als „Dieser PC“.
- Meldungen, die älter als 7 Tage sind, zeigt das Dashboard nicht mehr.
- Schaltest du den Server-Modus aus oder meldest du das Server-Gerät ab, verschwindet es aus den Dashboards der anderen Geräte.
- Antwortet der Server nicht, bleiben die zuletzt bekannten Stände der Server-Geräte noch etwa 2 Minuten stehen. Danach zeigen die Karten nur noch diesen PC.

## 14. Abo: Warnleiste und Karte Dein Abo

Cash Lister wird als **Monatsabo** abgerechnet. Laut den AGB auf https://cash-lister.de (§ 5) kostet es **150 € pro Monat für den ersten Shop und 50 € für jeden weiteren Shop**, jeweils **zzgl. 19 % USt** (Nettopreise). Ein Shop ist ein eBay-Verkäuferkonto. Beispiel: 2 Shops = 150 € + 50 € = 200 € netto, mit 19 % USt also 238 € im Monat.

Im Dashboard gibt es dazu zwei Anzeigen: eine **Warnleiste** oben (nur bei Bedarf) und die **Karte „Dein Abo“** unten. Was das Abo allgemein regelt (Vertrag, Zahlungsseite, Kündigung), steht in den AGB auf https://cash-lister.de und in `konto-und-installation.md`.

### 14.1 Wann die Abo-Anzeigen erscheinen

Die Karte „Dein Abo“ und die Warnleiste erscheinen nur, wenn

- du angemeldet bist **und**
- für deinen Zugang eine Abrechnung läuft **und**
- die Extension den Abo-Stand schon einmal vom Server geholt hat.

Den Stand holt die Extension bei jeder erfolgreichen Prüfung deiner Anmeldung (beim Anmelden, beim Öffnen des Dashboards, beim Chrome-Start und regelmäßig im Hintergrund) und wenn du aus dem Kundenportal oder von der Zahlungsseite zurück zum Dashboard kommst. Ist der Server einmal nicht erreichbar, bleibt der zuletzt bekannte Stand stehen.

Siehst du keine Karte „Dein Abo“, kann das heißen: Für deinen Zugang läuft (noch) keine Abrechnung, oder der Stand ist noch nicht geladen. Erwartest du die Karte, frag den Betreiber.

### 14.2 Die Warnleiste oben

Gibt es beim Abo etwas zu tun, erscheint direkt unter dem Kopf eine **orange oder rote Leiste** mit Warnzeichen, Überschrift, Text und (wenn die Extension deine Zahlungsseite kennt) einem Knopf. Derselbe Hinweis steht zusätzlich ganz oben in der Glocke.

| Überschrift | Text | Knopf |
|---|---|---|
| „Zahlung offen“ | „Ohne Zahlung wird dein Zugang nach dem 03.11.2026 gesperrt.“ bzw., wenn der Tag schon vorbei ist, „Die Sperre ist fällig – bitte jetzt bezahlen.“ | „Jetzt bezahlen“ |
| „Zahlung überfällig“ | „Die Abbuchung hat nicht geklappt. “ + Satz zur Sperre wie oben | „Jetzt bezahlen“ |
| „Erste Zahlung fehlgeschlagen“ | „Die erste Abbuchung hat nicht geklappt. “ + Satz zur Sperre wie oben | „Jetzt bezahlen“ |
| „Abo gesperrt“ | „Ein Shop deines Abos ist wegen einer offenen Zahlung gesperrt.“ | „Jetzt bezahlen“ |
| „Noch kein Abo eingerichtet“ (erst ab 7 Tagen vor dem Ende deines Zugangs) | „Dein Zugang läuft bis 03.11.2026. Richte das Abo auf der Zahlungsseite ein, damit es weitergeht.“ bzw. „Dein Zugang ist abgelaufen. Richte das Abo …“ | „Abo einrichten“ |
| „Abo beendet“ (erst ab 7 Tagen vor dem Ende deines Zugangs) | wie bei „Noch kein Abo eingerichtet“ | „Abo einrichten“ |

- **Rot** statt orange wird die Leiste, wenn weniger als 2 Tage bis zur Sperre bleiben oder die Lage ernst ist (überfällig, fehlgeschlagen, gesperrt).
- Der Knopf öffnet deine **Zahlungsseite** in einem neuen Tab ([14.5](#145-die-zahlungsseite)). Kennt die Extension sie nicht, fehlt der Knopf. Dann frag den Betreiber nach deinem Zahlungslink.
- Das Datum („nach dem …“, „bis …“) ist der **letzte Tag**, an dem dein Zugang noch läuft.

### 14.3 Die Karte Dein Abo

Die Karte steht ganz unten im Dashboard. Sie zeigt:

**Kopfzeile:** „Dein Abo“, ein farbiges Schild mit dem Zustand und daneben ein Satz zum Stand.

| Schild | Farbe | Bedeutung |
|---|---|---|
| „aktiv“ | grün | Abo läuft, bezahlt. |
| „eingerichtet“ | blau | Abo ist eingerichtet, die erste Abbuchung kommt noch. |
| „Zahlung unterwegs“ | blau | Eine Lastschrift ist unterwegs und noch nicht bestätigt. |
| „gekündigt“ | orange | Du hast gekündigt; das Abo läuft bis zum Ende des bezahlten Zeitraums. |
| „Zahlung offen“ | orange | Eine Zahlung steht aus. |
| „kein Abo“ | orange | Es ist noch kein Abo eingerichtet. |
| „beendet“ | orange | Das Abo ist beendet. |
| „überfällig“ | rot | Eine Abbuchung hat nicht geklappt. |
| „Zahlung fehlgeschlagen“ | rot | Die erste Abbuchung hat nicht geklappt. |
| „gesperrt“ | rot | Ein Shop deines Abos ist gesperrt. |

Der Satz daneben kommt vom Server, zum Beispiel:

- „Aktiv bis 30.11.2026 – nächste Abbuchung 01.12.2026“
- „Eingerichtet – erste Abbuchung am 01.12.2026“
- „Lastschrift unterwegs – Sperre spätestens 15.11.2026“
- „Gekündigt zum 30.11.2026 – Zugang bis 03.12.2026“
- „Aktiv, Zahlung offen – Sperre ab 04.11.2026“
- „Überfällig seit 01.12.2026 – Sperre ab 04.12.2026“
- „Kein Abo – Zugang bis 03.11.2026“
- „Abo beendet – Zugang bis 03.11.2026“
- „Erste Zahlung fehlgeschlagen – Sperre ab 04.11.2026“
- „Gesperrt seit 04.11.2026“
- Ist der Sperrtag schon vorbei, steht statt „Sperre ab …“ z. B. „… – Sperre fällig seit 04.11.2026“.

**Nicht sicher belegt:** Diese Sätze kommen vom Server. Der genaue Wortlaut kann abweichen. Erklär dem Kunden den Sinn, nicht jedes Wort.

**Drei Felder darunter:**

| Feld | Inhalt |
|---|---|
| „Shops“ | wie viele Shops dein Abo umfasst |
| „Monatlich“ | der Monatsbetrag netto, z. B. „200 €“, darunter klein „zzgl. 19 % USt“ |
| drittes Feld, je nach Stand | „Erste Abbuchung“ (bei „eingerichtet“), „Gekündigt zum“ (bei „gekündigt“: der letzte Tag des bezahlten Zeitraums) oder „Zugang bis“ (bei offen, überfällig, fehlgeschlagen, kein Abo, beendet). Bei „aktiv“ fehlt es; die nächste Abbuchung steht dann schon im Satz oben. Auch bei „Zahlung unterwegs“ und „gesperrt“ gibt es kein drittes Feld. |

**Knöpfe unten:**

- „**Abo verwalten**“ öffnet das Kundenportal ([14.4](#144-abo-verwalten-kundenportal)).
- „**Zahlungsseite**“ (nur wenn bekannt) öffnet deine persönliche Zahlungsseite in einem neuen Tab ([14.5](#145-die-zahlungsseite)).

Rechts neben den Knöpfen (im schmalen Fenster darunter) steht: „Kündigen, Zahlungsart ändern, Rechnungen: alles im Kundenportal unter „Abo verwalten“.“ In dieser Zeile erscheinen auch die Meldungen zu „Abo verwalten“.

Alle Daten der Abo-Anzeigen gelten in deutscher Zeit.

### 14.4 Abo verwalten (Kundenportal)

Über „Abo verwalten“ kommst du ins **Kundenportal**. Laut AGB ist das das Kundenportal des Zahlungsdienstleisters Stripe. Dort kannst du laut Hinweis auf der Karte:

- **Rechnungen** ansehen und herunterladen,
- die **Zahlungsart** ändern,
- **kündigen**.

So geht's:

1. Dashboard öffnen (angemeldet).
2. Ganz unten in der Karte „Dein Abo“ auf „**Abo verwalten**“ klicken.
3. Neben den Knöpfen steht kurz „Kundenportal wird geöffnet …“ (der Knopf ist so lange gesperrt).
4. Das Kundenportal öffnet sich in einem **neuen Tab**. Auf der Karte steht „Kundenportal im neuen Tab geöffnet.“
5. Erledige dort, was du willst.
6. Wechsle zurück zum Dashboard-Tab. Das Dashboard holt den Abo-Stand dann von selbst neu.

**Kündigen:** Laut AGB (§ 7) kannst du jederzeit **zum Ende des laufenden Abrechnungszeitraums** kündigen, über das Kundenportal oder per E-Mail an die Adresse im Impressum. Nach einer Kündigung zeigt die Karte „gekündigt“ und das Feld „Gekündigt zum“. Bis dahin kannst du Cash Lister weiter nutzen.

**Rechnungen:** Laut AGB (§ 6) bekommst du sie als PDF per E-Mail oder findest sie im Kundenportal.

Meldungen neben den Knöpfen, in der Zeile des Erklärtexts (nach 10 Sekunden kehrt der Erklärtext zurück):

| Meldung | Bedeutung | Was tun |
|---|---|---|
| „Kundenportal im neuen Tab geöffnet.“ | Hat geklappt. | Im neuen Tab weitermachen. |
| „Noch kein Abo eingerichtet – das geht über die Zahlungsseite.“ | Es gibt noch kein Abo, also auch kein Kundenportal. Der Knopf „Zahlungsseite“ erscheint. | Über „Zahlungsseite“ das Abo einrichten. |
| „Noch kein Abo eingerichtet – bitte beim Betreiber melden.“ | Kein Abo, und die Zahlungsseite ist nicht bekannt. | Betreiber nach dem Zahlungslink fragen. |
| „Bitte <Zahl> Sekunden warten.“ | Zu schnell hintereinander geklickt. | Kurz warten, dann noch einmal. |
| „Server nicht erreichbar – bitte später erneut versuchen.“ | Der Server antwortet nicht. | Später noch einmal. |
| „Kundenportal gerade nicht erreichbar – bitte später erneut versuchen.“ | Das Kundenportal ließ sich gerade nicht öffnen. | Später noch einmal; hält es an, Betreiber. |
| „Nicht angemeldet.“ oder „Zugang gesperrt.“ (bzw. ein Sperrtext) | Du bist nicht (mehr) angemeldet bzw. gesperrt. | Neu anmelden bzw. [9.7](#97-abo-gesperrt). |

**Nicht sicher belegt:** Wie das Kundenportal im Einzelnen aussieht und welche Knöpfe es dort genau gibt, steht nicht in der Extension. Das weiß diese Hilfe nicht sicher.

### 14.5 Die Zahlungsseite

Die **Zahlungsseite** ist deine persönliche Seite zum Abo. Den Link bekommst du vom Betreiber; die Extension zeigt ihn als „Zahlungsseite“, „Jetzt bezahlen“, „Abo einrichten“ oder „Zur Zahlungsseite“ an, sobald sie ihn kennt. Laut AGB (§ 3) nennt die Zahlungsseite die Anzahl der Shops, den Monatspreis und den Tag der ersten Abbuchung. Beim Abschluss des Abos bestätigst du mit einem Pflicht-Haken, dass du als Unternehmer handelst, und stimmst den AGB zu. Ohne diesen Haken geht es nicht. Cash Lister gibt es laut AGB nur für Unternehmer.

Mehr zum Abschluss und zur Zahlungsseite steht in `konto-und-installation.md` und in den AGB auf https://cash-lister.de (dort auch Datenschutz und Impressum).

### 14.6 Sperre und Freischaltung nach der Zahlung

- **Wann gesperrt wird:** Laut AGB (§ 6) kann der Zugang gesperrt werden, wenn das Entgelt drei Tage nach Fälligkeit nicht bezahlt ist. Bei Lastschrift wartet der Betreiber laut AGB länger, solange der Einzug läuft. Den konkreten Tag zeigen dir die Warnleiste und die Karte („Zugang bis …“, „Sperre ab …“).
- **Was bei einer Sperre passiert:** Die Module sperren sich, das Dashboard zeigt die Anmeldekarte mit „Abo gesperrt“ ([9.7](#97-abo-gesperrt)). Laut AGB bleiben dein Benutzerkonto und deine gesicherten Einstellungen erhalten. Was mit reservierten Produkten passiert, regelt § 6 und § 8 der AGB; Fragen dazu an den Betreiber.
- **Nach der Zahlung:** Laut AGB hebt der Betreiber die Sperre nach Eingang der Zahlung unverzüglich auf, in der Regel automatisch. Danach meldest du dich im Dashboard neu an.

**Nicht sicher belegt:** Wie lange es nach der Zahlung genau dauert, bis die Anmeldung wieder klappt (besonders bei Lastschrift), weiß diese Hilfe nicht sicher. Frag im Zweifel den Betreiber.

Diese Hilfe kann keine Zahlungsfristen verlängern, Sperren aufheben oder Preise zusagen. Das macht nur der Betreiber.

## 15. Wenn der Server nicht erreichbar ist

Antwortet der Server nicht (Internet weg, Wartung, Störung), siehst du im Dashboard:

| Wo | Was |
|---|---|
| Seitenleiste unten | orangener Punkt, „Server nicht erreicht“, „antwortet nicht seit …“ bzw. „zuletzt erreicht …“, „Lister nehmen keine Produkte“ |
| Kopfzeile | „… · Server nicht erreicht“ |
| Kontomenü | „Angemeldet · Server nicht erreicht“ |
| Glocke | Hinweis „Server nicht erreicht“ ([Abschnitt 7](#7-die-glocke-hinweise)) |
| Kachel „Produkte in der Datenbank“ | „–“ mit „Server nicht erreichbar“ |
| Karte „Produkte sammeln“ | Marker „nicht erreichbar“, „Produkt-Datenbank: Server nicht erreichbar“ |
| Karte „Browser-Lister“ (wenn ein Lauf läuft) | Marker „wartet auf den Server“, „Server nicht erreichbar seit … – macht von selbst weiter · … gelistet“ |
| Checkliste | „Produkt-Datenbank: Server nicht erreichbar“, ggf. „Server nicht erreicht – wird wiederholt“ bei der Sicherung |
| Server-Geräte | nach etwa 2 Minuten ohne Antwort verschwinden ihre Stände; die Karten zeigen nur noch diesen PC |
| Karte „Dein Abo“ | bleibt mit dem zuletzt bekannten Stand stehen |

Was das für dich bedeutet:

- **Meist genügt Warten.** Sobald der Server wieder antwortet, steht unten in der Seitenleiste wieder „Server verbunden“ (Neuladen des Dashboards beschleunigt das). Einen CSV-Lister-Lauf startest du danach neu.
- **Die Lister nehmen keine neuen Produkte.** Der Browser-Lister wartet und **macht von selbst weiter**, sobald der Server wieder antwortet. Du musst ihn nicht neu starten, aber sein Tab muss offen bleiben. Der CSV-Lister nimmt ebenfalls keine Produkte (Details in `produktuebersicht-und-csv-lister.md`).
- **Die Produkt-Datenbank ist nicht weg.** Die Zahl ist nur gerade unbekannt.
- **Die Sicherung deiner Einstellungen** wird später von selbst wiederholt.
- **Anmelden geht nicht**, solange der Server weg ist („Server nicht erreichbar (…). Adresse prüfen oder später erneut versuchen.“).
- **„Abo verwalten“ geht nicht** („Server nicht erreichbar – bitte später erneut versuchen.“).

Was du tun kannst:

1. Internetverbindung prüfen (öffnet sich z. B. eine andere Webseite?).
2. Ein paar Minuten warten. Die Anzeige wird von selbst wieder grün, sobald die Extension den Server wieder erreicht.
3. Das Dashboard mit F5 neu laden. Beim Neuladen prüft die Extension die Verbindung sofort neu.
4. Die Server-Adresse **nicht** ändern, außer der Betreiber sagt es ([9.4](#94-server-adresse-nur-auf-ansage-ändern)).
5. Hält die Störung länger an, beim Betreiber melden (mit Uhrzeit, seit wann).

Hinweis: Nach dem Chrome-Start oder nach dem Aufwachen des PCs kann kurz „Server nicht erreicht“ stehen, bis die erste Prüfung durch ist. Das verschwindet von selbst.

## 16. Wie aktuell das Dashboard ist

- Das Dashboard **aktualisiert sich selbst**, solange sein Tab sichtbar ist. Du musst nicht ständig F5 drücken.
- Ungefähre Abstände: Anzeigen aus diesem PC alle 5 Sekunden, Stand der Lister und der Sicherung alle 15 Sekunden, Produkt-Datenbank und Server-Geräte alle 30 Sekunden, Verkaufs-Übersicht alle 2 Minuten. Die Seitenleiste frischt sich etwa alle 15 Sekunden auf.
- Ist der Tab im Hintergrund (anderer Tab vorne, Fenster minimiert), ruht das Dashboard. Sobald du wieder hinschaust, holt es alles neu.
- Direkt nach dem Öffnen stehen manche Werte kurz auf „…“ oder „wird geladen“. Die Extension im Hintergrund muss dafür manchmal erst „aufwachen“. Das dauert meist nur ein paar Sekunden.
- **F5 (neu laden)** prüft zusätzlich gleich die Anmeldung beim Server.
- Nach dem Anmelden oder Abmelden baut sich das Dashboard sofort neu auf.

## 17. Farben und Zeichen

**Marker (Schilder auf den Karten):**

| Farbe | Bedeutung |
|---|---|
| grün | in Ordnung, fertig, bereit, aktiv |
| blau | läuft gerade bzw. geplant (z. B. „nächster Lauf …“, „Pause bis …“) |
| orange | Achtung: pausiert, unterbrochen, wartet, Zahlung offen |
| rot | ernst: angehalten, überfällig, gesperrt, fehlgeschlagen |
| grau | neutral: bereit ohne Lauf, unbekannt („–“) |

**Punkt in der Seitenleiste:** grün = verbunden, orange = Server nicht erreicht, rot = Zugang abgeschaltet oder Abo gesperrt, grau = nicht angemeldet.

**Punkt an der Glocke:** türkis = es gibt Hinweise, rot = mindestens ein ernster Hinweis.

**Kreise in der Checkliste:** grün mit Haken = erledigt, blau mit Pfeilen = läuft, orange mit Ausrufezeichen = Achtung, leer = offen.

**Symbole in der untersten Zeile der Vorgangskarten:** Fenster = Tab auf diesem PC; Raster = „Dieser PC“ (wenn es Server-Geräte gibt); Wolke = Stand kommt von einem Server-Gerät.

**Zeichen statt Zahlen:** „…“ = wird geladen; „–“ = gerade nicht bekannt (Grund steht darunter).

## 18. Häufige Fragen

**Seit dem Update geht beim Klick auf das Symbol kein kleines Fenster mehr auf, sondern eine ganze Seite. Ist das richtig?**
Ja. Seit Version 46.0 gibt es das kleine Fenster (Popup) nicht mehr. Ein Klick auf das Symbol öffnet das Dashboard in einem Tab, oder springt dorthin, wenn es schon offen ist.

**Wo melde ich mich jetzt an?**
Im Dashboard. Bist du nicht angemeldet, steht oben die Anmeldekarte mit „Benutzername“, „Passwort“ und „Anmelden“ ([9.2](#92-anmelden-mit-benutzername-und-passwort)). Alternativ rechts „Einrichtungsdatei einlesen“ ([9.3](#93-anmelden-mit-der-einrichtungsdatei)).

**Wo melde ich mich ab?**
Oben rechts auf das Kontofeld klicken (dein Name), dann „Abmelden“ ([Abschnitt 8](#8-das-kontofeld-und-abmelden)).

**Wo stelle ich jetzt die Preise ein (Aufschlag, End Price, Domain …)?**
In den Einstellungen: Seitenleiste → „Einstellungen“ → Reiter „Preise & Listing“. Dort heißen die Felder z. B. „% Aufschlag“, „Fester Aufschlag (€)“, „Preisendung“ (früher „End Price“) und „Domain“. Was jedes Feld bedeutet, steht in `einstellungen.md`.

**Wo sehe ich, welche Version ich habe?**
Unten in der Seitenleiste, z. B. „Version 46.0“ ([4.4](#44-versionsnummer)). Ist das Fenster schmal, ist die Nummer ausgeblendet; dann das Fenster breiter ziehen oder maximieren.

**Muss das Dashboard offen bleiben, damit Tracker oder Browser-Lister laufen?**
Nein. Das Dashboard zeigt nur an. Offen bleiben muss der **Tab des Moduls**, in dem der Lauf läuft (Tracker bzw. Browser-Lister).

**Ich habe auf „Tracker“ geklickt, aber es ging kein neuer Tab auf.**
Der Tracker war schon offen. Cash Lister springt dann in den offenen Tab, auch wenn er in einem anderen Chrome-Fenster liegt ([Abschnitt 5](#5-module-öffnen-eigener-tab-kein-zweiter-tab)).

**Warum sind die Module in der Seitenleiste grau?**
Du bist nicht angemeldet, dein Zugang ist abgeschaltet oder dein Abo ist gesperrt. Schau oben im Dashboard in die Anmeldekarte ([Abschnitt 9](#9-die-anmeldekarte)).

**Was heißt „in Arbeit“ bei der Produkt-Datenbank?**
Diese Produkte hat gerade ein Lister (auf irgendeinem deiner Geräte) entnommen, um sie zu listen. Sie werden nicht doppelt vergeben ([10.2](#102-produkte-in-der-datenbank)).

**Ich habe zwei PCs. Sehe ich auf beiden dieselben Produkte?**
Ja, wenn beide mit demselben Zugang angemeldet sind. Die Produkt-Datenbank liegt seit 46.0 je Konto auf dem Server.

**Warum zählt „Heute gelistet“ meinen zweiten PC nicht mit?**
Mitgezählt werden nur dieser PC und Geräte, auf denen der Server-Modus eingeschaltet ist ([Abschnitt 13](#13-server-geräte-server-modus-im-dashboard)).

**Die Tracker-Karte zeigt „Server-1“, aber ein Klick öffnet den Tracker auf meinem PC. Warum?**
Die Karte zeigt den wichtigsten Stand aller Geräte, ein Klick öffnet aber immer das Modul auf dem PC, vor dem du sitzt. Den Lauf auf „Server-1“ steuerst du auf diesem Gerät selbst.

**Bei „Aktive Angebote“ steht „–“.**
Auf diesem PC wurde noch kein Angebotsbericht im Tracker oder in der Verkaufs-Übersicht eingelesen. Das ist normal, wenn dein Tracker nur auf einem anderen Gerät läuft ([10.1](#101-aktive-angebote)).

**Die Glocke ist leer, obwohl ich nicht angemeldet bin.**
Ohne Anmeldung zeigt die Glocke keine Hinweise. Melde dich zuerst an.

**Wo finde ich meine Rechnungen vom Abo?**
Im Dashboard ganz unten in der Karte „Dein Abo“ → „Abo verwalten“ → im Kundenportal. Laut AGB kommen sie außerdem als PDF per E-Mail ([14.4](#144-abo-verwalten-kundenportal)).

**Wie kündige ich das Abo?**
Karte „Dein Abo“ → „Abo verwalten“ → im Kundenportal kündigen. Laut AGB geht das jederzeit zum Ende des laufenden Abrechnungszeitraums, auch per E-Mail an die Adresse im Impressum ([14.4](#144-abo-verwalten-kundenportal)).

**Wie ändere ich meine Zahlungsart (Karte, Lastschrift)?**
Karte „Dein Abo“ → „Abo verwalten“ → im Kundenportal.

**Was kostet Cash Lister?**
Laut AGB 150 € im Monat für den ersten Shop und 50 € für jeden weiteren, zzgl. 19 % USt. Deinen Betrag zeigt die Karte „Dein Abo“ unter „Monatlich“ ([Abschnitt 14](#14-abo-warnleiste-und-karte-dein-abo)). Individuelle Absprachen kennt diese Hilfe nicht; dafür den Betreiber fragen.

**Ich sehe keine Karte „Dein Abo“.**
Siehe [14.1](#141-wann-die-abo-anzeigen-erscheinen). Erwartest du sie, frag den Betreiber.

**Was heißt „Zahlung unterwegs“?**
Eine Lastschrift ist eingezogen, aber noch nicht bestätigt. Laut AGB steht bei Lastschrift erst einige Werktage nach dem Einzug fest, ob sie geklappt hat. Du musst nichts tun; sorge nur dafür, dass dein Konto gedeckt ist. Der Satz neben dem Schild nennt, bis wann spätestens („Sperre spätestens …“).

**Brauche ich eine Freischaltung für den CSV-Lister?**
Nein. Seit Version 46.0 steht der CSV-Lister für alle Kunden in der Seitenleiste und unter „Vorgänge“. Fehlt er bei dir, schau unten in der Seitenleiste nach der Version. Steht dort eine ältere als 46.0, aktualisiere wie in [9.8](#98-veraltete-version) (Schritte 1 bis 3). Fehlt er auch mit 46.0, frag den Betreiber.

**Kann ich die Server-Adresse ändern?**
Nur, wenn der Betreiber es dir sagt ([9.4](#94-server-adresse-nur-auf-ansage-ändern)).

**Was bedeutet „Produkt-Vergabe aktiv“ unten in der Leiste?**
Die Funktion, die doppeltes Listen zwischen Kunden verhindert, arbeitet. Dafür braucht es Anmeldung und Server ([4.3](#43-server-stand-unten-in-der-leiste)).

## 19. Probleme und Lösungen

**Klick auf das Symbol öffnet weiterhin das alte kleine Fenster (oder gar nichts).**
Wahrscheinlich läuft nach dem Update noch die alte Version im Hintergrund.
1. Chrome **komplett** schließen (alle Fenster; unten rechts im Infobereich prüfen, ob Chrome noch läuft) und neu starten.
2. Hilft das nicht: `chrome://extensions` öffnen und bei Cash Lister auf „Neu laden“ (runder Pfeil) klicken.
3. Danach noch einmal auf das Symbol klicken. Unten in der Seitenleiste muss die neue „Version …“ stehen.
4. Hilft das alles nicht, beim Betreiber melden.

**Nicht sicher belegt:** Dass genau in diesem Fall noch das alte Fenster erscheint, ist eine naheliegende Erklärung, aber nicht ausdrücklich geprüft.

**Das Dashboard bleibt lange auf „…“, „wird geladen“, „Stand nicht verfügbar“ oder die Browser-Lister-Karte zeigt „Keine Antwort vom Hintergrunddienst“.**
Die Extension im Hintergrund antwortet nicht.
1. 10 bis 20 Sekunden warten.
2. Dashboard mit F5 neu laden.
3. Bleibt es so: Hintergrunddienst aktualisieren (Chrome komplett neu starten, sonst `chrome://extensions` → „Neu laden“). Siehe `konto-und-installation.md`.

**„Server nicht erreicht“ steht dauerhaft da.**
Siehe [Abschnitt 15](#15-wenn-der-server-nicht-erreichbar-ist). Internet prüfen, warten, F5. Hält es an, Betreiber fragen. Server-Adresse nicht auf eigene Faust ändern.

**Anmelden klappt nicht.**
Die genaue Meldung in [9.5](#95-alle-meldungen-beim-anmelden) nachschlagen. Häufigste Fälle: Tippfehler („Name oder Passwort falsch.“) → Einrichtungsdatei nutzen; alte Version („… veraltet …“) → [9.8](#98-veraltete-version); „Keine Antwort vom Hintergrunddienst …“ → Hintergrunddienst aktualisieren.

**Nach dem Anmelden passiert nichts; die Anmeldekarte bleibt stehen, keine Meldung.**
1. 30 Sekunden warten. Dann erscheint entweder eine Meldung, oder die Karte verschwindet.
2. Kommt „Keine Antwort vom Hintergrunddienst – bitte noch einmal versuchen.“: Hintergrunddienst aktualisieren und noch einmal anmelden.

**„Abo gesperrt“ in der Anmeldekarte.**
Siehe [9.7](#97-abo-gesperrt): Zahlungsseite öffnen, bezahlen, neu anmelden. Hilft das nicht, Betreiber.

**„Zugang abgeschaltet“.**
Beim Betreiber melden ([9.6](#96-zugang-abgeschaltet)).

**Die Produktzahl zeigt „–“ mit „Sitzung abgelaufen – bitte im Dashboard neu anmelden.“**
Deine Anmeldung ist abgelaufen. Kurz darauf erscheint die Anmeldekarte. Neu anmelden.

**Die Produktzahl zeigt „0“ mit „… werden noch auf den Server übertragen“.**
Kein Fehler. Die alte Liste dieses PCs wird gerade hochgeladen ([10.2](#102-produkte-in-der-datenbank)). Angemeldet bleiben und warten. Bleibt die Zahl über längere Zeit gleich, beim Betreiber melden.

**„alle in Arbeit“ bei „Produkte sammeln“, obwohl gerade nichts läuft.**
Alle Produkte sind gerade von einem Lister entnommen, vielleicht auf einem anderen Gerät oder von einem abgebrochenen Lauf. Prüfe deine anderen Geräte. Sammle neue Produkte, wenn du sofort weiterlisten willst. Solche Produkte werden von selbst wieder frei. Wie lange, zeigt die Produkt-Datenbank in der Spalte „In Arbeit“ an der Uhrzeit hinter „bis“. Cash Lister verlangt dabei beim Browser-Lister etwa 30 Minuten (laufend verlängert, solange er arbeitet), beim CSV-Lister etwa 1 Stunde bzw. bis zu 7 Tage für Produkte, die schon in einer hochgeladenen Datei stehen (`references/produkte-finden-und-datenbank.md`, Abschnitt 10.9). **Nicht sicher belegt:** ob der Server diese Zeiten in jedem Fall genau so übernimmt – bei Fragen an den Betreiber wenden.

**Die Tracker-Karte zeigt „unterbrochen“.**
Der Tracker-Tab wurde geschlossen, während ein Lauf lief. Tracker über die Karte öffnen und den Lauf dort fortsetzen (siehe `tracker.md`). Steht „auf <Gerätename> im Tracker fortsetzen“ dabei, musst du das auf dem Server-Gerät tun.

**Die Browser-Lister-Karte zeigt „Tab geschlossen“.**
Der Tab des Laufs ist zu. Der Lauf endet nach dem aktuellen Produkt (bzw. nach der Pause der Zeitschaltung). Ein neu geöffneter Browser-Lister-Tab rettet ihn nicht. Starte bei Bedarf einen neuen Lauf (siehe `listen-auf-ebay.md`).

**Ein Server-Gerät „meldet sich nicht“.**
Prüfe auf dem Server-Gerät: Läuft Chrome? Ist Cash Lister geladen? Gibt es Internet? Bist du dort angemeldet? Ist unter Einstellungen → „eBay & Rahmenbedingungen“ → „Server-Modus“ der Schalter „Dieses Gerät ist ein Server“ noch an? Brauchst du das Gerät nicht mehr, schalte dort den Server-Modus aus. Dann verschwindet es aus den Dashboards.

**Die Checkliste meldet „Ein anderes Gerät hat anders gesichert …“.**
Zwei Geräte haben unterschiedliche Einstellungen gesichert. Unter Einstellungen → Reiter „Sicherung“ entscheiden, welcher Stand gilt (siehe `einstellungen.md` bzw. `konto-und-installation.md`).

**„Abo verwalten“ öffnet nichts.**
Meldung neben den Knöpfen lesen ([14.4](#144-abo-verwalten-kundenportal)). Steht dort „Kundenportal im neuen Tab geöffnet.“, schau in der Tab-Leiste nach dem neuen Tab. Steht dort eine Fehlermeldung, später noch einmal versuchen; hält es an, Betreiber.

**Der Knopf „Zur Zahlungsseite“ bzw. „Jetzt bezahlen“ fehlt.**
Die Extension kennt deine Zahlungsseite noch nicht. Frag den Betreiber nach deinem persönlichen Zahlungslink.

**Die Karte „Dein Abo“ zeigt einen alten Stand.**
Dashboard mit F5 neu laden oder ein paar Minuten warten. Kommst du gerade aus dem Kundenportal, wechsle einfach zurück zum Dashboard-Tab; es fragt dann neu nach. Ist der Server nicht erreichbar, bleibt der letzte Stand stehen.

## 20. Was diese Hilfe nicht sicher weiß

- **Mindestversion:** Welche Version mindestens nötig ist, um sich anzumelden, legt der Betreiber fest. Frag den Betreiber.
- **„In Arbeit“-Dauer:** Belegt ist, welche Haltezeit Cash Lister verlangt (Browser-Lister etwa 30 Minuten, CSV-Lister etwa 1 Stunde bzw. bis zu 7 Tage) und dass die Uhrzeit hinter „bis“ in der Produkt-Datenbank den gerade gültigen Stand zeigt. Ob der Server diese Zeiten in jedem Fall genau so übernimmt, ist nicht belegt. Frag im Zweifel den Betreiber.
- **Freischaltung nach Zahlung:** Wie lange es nach einer Zahlung genau dauert, bis die Anmeldung wieder klappt (vor allem bei Lastschrift), ist nicht belegt. Laut AGB „unverzüglich, in der Regel automatisch“.
- **Kundenportal:** Wie das Kundenportal im Einzelnen aussieht, steht nicht in der Extension.
- **Statussätze der Abo-Karte:** Sie kommen vom Server; der genaue Wortlaut kann von den Beispielen abweichen.
- **Altes Popup nach dem Update:** Dass bei einem noch nicht neu geladenen Hintergrunddienst das alte Fenster erscheint, ist eine naheliegende Erklärung, aber nicht ausdrücklich geprüft.
- **Fristen des Servers:** Reservierungsdauern, Inaktivitätsfristen und andere Einstellungen des Servers nennt diese Hilfe nicht. Was dazu in den AGB steht, steht dort; alles Weitere weiß der Betreiber.
